# ImmunoAudit 代码说明

本包整理 ImmunoAudit 的分析实现、必要共用函数、LLM 提示模板和离线测试。
不含 API key、原始数据、患者级预测、请求缓存、模型权重、历史版本、旧图修订链或手稿构建脚本。
当前绘图脚本依赖历史修订链，因此本包暂不提供论文图片的一键重绘。

## 运行与路径

先阅读 `README.md`，安装依赖，再运行：

```bash
python scripts/verify_submission.py
python scripts/run_offline_tests.py
python run.py --help
```

路径通过 `--project-root`、`--data-root`、`--models-root` 指定。
各分析的输出目录通过 `--` 后面的 `--output-dir` 或 `--output-root` 指定。
默认项目目录为解压后的代码包；如果指定另一项目目录，须将代码包复制到那里，
并按 `INPUTS.md` 放置获准使用的输入。请勿直接指向原来的历史工作目录。

API key 只通过环境变量提供，不能作为命令行参数，也不会写入示例配置。
本次整理没有调用 API、下载权重或重跑真实数据实验。

## 复现范围

离线测试只使用合成数据；它不等于论文结果的完整独立复现。
完整分析仍需另行提供特征矩阵、患者分组、临床表及固定模型预测等必要输入。
保留固定预测是当前统计方案的一部分，不是把历史代码版本重新加入提交包。

原始项目、原始密钥配置和手稿均保持不变。提交前仍需由作者决定软件许可证，
并确认期刊是否要求另附研究数据或独立的绘图代码。
